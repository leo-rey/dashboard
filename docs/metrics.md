# Indicadores

- Contato trabalhado, convite, mensagem, resposta, conversa e reunião são contagens confirmadas dos lotes/eventos persistidos.
- Pipeline aberto soma oportunidades em estágios não encerrados.
- Pipeline ponderado soma `valor × probabilidade / 100` das oportunidades abertas.
- Uma conexão aceita ou reunião institucional não cria oportunidade automaticamente.
- Lotes históricos agregados não são convertidos em eventos individuais sem evidência.
